## Priority issues

### 1. [P2] Configuration serves two different reading tasks

`website/src/content/docs/docs/configuration.mdx:13-44,150+`

The page measured approximately **23,167px tall on mobile**. Length alone is not a defect, but first-time setup and exhaustive key lookup require different structures. Stacking every reference row increases the scan cost.

**Fix:** keep common setup, member discovery, exclusions, and verification in the guide. Move exhaustive keys and advanced reference material to a linked configuration reference, preserving existing anchor destinations.

**Suggested command:** `/impeccable distill website/src/content/docs/docs/configuration.mdx`

### 2. [P2] The generated CLI reference skips heading levels

`website/src/content/docs/docs/reference.md:69,88,111,143` and repeated sections

"Subcommands," "Arguments," and "Options" use level-six headings directly beneath level-two command headings. This makes the document outline harder to navigate with a screen reader.

**Fix:** correct heading depth in the documentation-generation path and regenerate with `just docs`. Do not patch the generated Markdown by hand.

**Suggested command:** `/impeccable harden website/src/content/docs/docs/reference.md`

### 3. [P2] Optional installation work interrupts verification

`website/src/content/docs/docs/installation.mdx:63-110`

Completions and man pages appear before version pinning and verification. Readers must pass optional enhancements before reaching proof that installation worked.

**Fix:** order the page as **choose method -> install -> verify -> pin for CI -> optional integrations**.

**Suggested command:** `/impeccable layout website/src/content/docs/docs/installation.mdx`

### 4. [P2] The homepage becomes a reference after proving its premise

`website/src/pages/index.astro:280-351`

The mobile homepage measured approximately **9,365px tall**. Its lifecycle section lists 14 commands after visitors have already seen the central argument. The primary CTA remains accessible, but continued evaluation requires too much scanning.

**Fix:** replace the command inventory with three concise outcomes linked to task running, versioning, and release automation. Preserve the ledger, derive/verify doctrine, and `doctor` reassurance.

**Suggested command:** `/impeccable distill website/src/pages/index.astro`
