## v1.0.0 - 2026-09-18


### trellis

#### Major

- **Pre-1.0 kebab-case configuration keys are no longer accepted.** Rename `needs-deps`, `series-tag-format`, `path-dep-requirement`, `initial-delay`, `header-format`, `version-format`, `kind-format`, and `change-format` to their snake_case forms; trellis now stops with an error that names the replacement.

#### Changed

- **Building trellis from source now requires Rust 1.88.** Prebuilt installers and the Homebrew package still require no Rust toolchain.

### changelog

#### Major

- **`changelog` removes its pre-1.0 aliases.** Unreleased fragments must use `package`, dependency templates must use `package`, and `changelog check` machine output must use `--format json` instead of `--json`.

### tag

#### Major

- **`series_tag_format` now requires `{name}`.** For one repository-wide moving tag, restore `{name}` in the package format and configure `repository_tag_package`, `repository_tag_format`, and `repository_tags`.

### ci

#### Major

- **`trellis ci outputs` no longer emits `projects`.** Read the identical `packages` output instead.
