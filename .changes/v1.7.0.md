## v1.7.0 - 2026-11-19


### release

#### Added

- **`release bootstrap` accepts required assets and draft finalization flags.** Select an exact package release with `--github-release --package NAME`, stage files with `--draft --asset FILE`, and publish with `--finalize` after all recorded uploads match. Recover incomplete operations at the original qualified revision; moving tags remain unchanged.

- **`release bootstrap --force=adopt` adopts repository aliases that predate the anchor manifest.** Adoption requires complete history and an alias commit that is an ancestor of HEAD with no prior anchor manifest at its current path. Preview with `--push --dry-run`; omit `--github-release` for Git-only releases. Exact tags remain immutable, newer anchor versions cannot move backward, and `--package` cannot be combined with adoption.

### tag

#### Added

- **`tag create` uploads required assets and finalizes package drafts after content verification.** Use `--github-release --package NAME --draft` with repeated `--asset FILE`, then `--finalize` to publish. Retries reuse matching uploads and retain every recorded requirement. Conflicts require `--replace-assets`; failed replacement uploads preserve existing assets. Recover at the original qualified revision, even after the default branch advances. Package-scoped operations leave moving tags unchanged. Unscoped GitHub release creation now rejects existing drafts instead of reporting them complete.

- **`tag plan` and `tag create` accept `--force=adopt` for legacy repository aliases.** The alias must be an ancestor of HEAD whose history never contained the anchor manifest at its current path. Shallow history, malformed manifests, backward version moves, and exact-tag conflicts remain errors. Preview with `--dry-run --push` before authorizing a move; previews leave local and remote tags unchanged.
